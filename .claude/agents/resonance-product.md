- **Conventions, hard rules:** all code lives in `resonance.html` (CSS in the one `<style>`, JS in the one inline `<script>` at the bottom). After ANY edit: `node -e "const fs=require('fs');const h=fs.readFileSync('resonance.html','utf8');const c=h.match(/<script>([\s\S]*?)<\/script>/)[1];try{new Function(c);console.log('JS OK')}catch(e){console.log('ERR '+e.message);process.exit(1)}"`, then confirm every `getElementById(...)` resolves to an id in the HTML, then confirm `<div>` open/close counts match.
